# Console ATM

A small Python ATM simulation with PIN login, balance checks, deposits, and
withdrawals. The account is in memory only, so the balance resets to `$1000.00`
each time the program starts. This is a learning demo, not a real banking system.

## Run

```powershell
python main.py
```

Demo PIN: `1234` (three attempts are allowed).

Run the unit tests with:

```powershell
python -m unittest
```
